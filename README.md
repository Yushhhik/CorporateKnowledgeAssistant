## О проекте

Telegram-бот, который отвечает на вопросы сотрудников по внутренней документации БАРС Груп (БАРС-Офис, БП «Командировка», реестр мебели, Garantexpress, Docsvision). 

В отличие от базовых RAG-решений, наш ассистент:
1. **Строго защищен от галлюцинаций**: если ответа нет в базе, бот честно говорит об этом и предлагает оператора (Вариант А), а не выдумывает факты.
2. **Поддерживает мультимодальность**: умеет анализировать скриншоты интерфейсов, присланные пользователем, и находить скриншоты внутри PDF-документов.
3. **Собирает продуктовую аналитику**: автоматически фиксирует "пробелы в знаниях" (вопросы без ответа) и оценки 👍/👎 для постоянного улучшения базы.
4. **Имеет умный парсер**: извлекает текст с сохранением иерархии заголовков, преобразует таблицы в читаемый вид («Ключ: Значение») и очищает колонтитулы.

## Стек технологий

- **Язык:** Python 3.11
- **Backend API:** FastAPI + Uvicorn
- **Telegram-бот:** aiogram 3.31 (FSM, middlewares)
- **Векторная БД:** Qdrant + эмбеддинги `intfloat/multilingual-e5-small` (384d)
- **Реляционная БД:** PostgreSQL + SQLAlchemy (Async)
- **Кэш и метрики:** Redis (асинхронный)
- **Аналитика:** SQLite + matplotlib (дашборды)
- **LLM (основная):** Ollama `qwen2.5vl:7b` (мультимодальная)
- **LLM (vision):** Ollama `qwen2.5vl:3b` (для ускоренного анализа изображений)
- **Парсинг документов:** `pdfplumber`, `python-docx`, `Pillow`, `pytesseract`, OpenAI Vision
- **Инфраструктура:** Docker, Docker Compose

## Быстрый старт

### 1. Скачивание моделей Ollama
Убедитесь, что Ollama запущен, и скачайте необходимые модели:
```bash
ollama pull qwen2.5vl:7b   # Основная мультимодальная модель
ollama pull qwen2.5vl:3b   # Легкая vision-модель для ускоренного анализа скриншотов
```

### 2. Настройка окружения
Создайте файл `.env` в корне проекта

### 3. Запуск проекта
**Весь проект (база данных, векторное хранилище, кэш, API и бот) запускается ОДНОЙ командой:**

```bash
docker-compose up --build
```

### 4. Индексация документов
Положите PDF/DOCX файлы в папку `api_service/docs/` и выполните индексацию:
```bash
docker exec -it <имя_контейнера_api> python ingest.py docs
# или для полной переиндексации:
# docker exec -it <имя_контейнера_api> python ingest.py docs --full
```
